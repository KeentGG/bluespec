# Prototype Docs

Human-readable documentation for the evolution prototype.

- `scope.md` explains MVP boundaries
- `decisions.md` records design decisions
- `data-model.md` explains entities, state split, and invariants
- `architecture-diagram.md` visualizes folders, scripts, state flow, and generated run artifacts
- `tasks.md` outlines milestones, phases, and task breakdowns for the evolution prototype

These docs explain intent; they are not authoritative machine state.
