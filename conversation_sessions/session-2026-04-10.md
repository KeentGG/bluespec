## Part 4: Non-Linear Exploration and Context Drift

**User:** alright, but what if there's no rigid spec structure to follow, like it depends on the code exploration does the spec format is based on, even if we have strict format for agents to follow like guide A -> B -> C, also B -> D -> C, etc... in the middle of context exploration, agent will hallucinate and not follow the rules, first research on how agentic tools like hermes agent, opencode, etc... so we know how to harness agentic tools better for instruction flows

**Agent:** Two hard problems identified:
1. Exploration is non-linear -- real code understanding is a graph, not a pipeline
2. Context drift -- the longer the agent works, the more it loses the format rules

Researched how existing agentic tools handle this. Found:

**LangGraph** -- uses state machines, not linear chains. Nodes are actions, edges are conditional routing. Can loop, branch, backtrack.

**Claude Code** -- uses sub-agents with isolated context. Each sub-agent has its own context window.

**OpenCode** -- state machine approach (`pick_next -> plan -> implement -> review`). External state file tracks progress.

**Context drift research:**
- The "35-minute rule": every agent degrades after ~35 minutes
- "Context rot" (Chroma Research, 2025): a million-token window doesn't mean you should use it all
- Solutions: explicit checkpoints, context compaction, sub-agent isolation, just-in-time context, external state files

Key insight: don't use prompt chains, use state machines with sub-agents. State lives in files, not context. Each step is a fresh sub-agent. Routing is conditional based on file state.

**Agent:** The breakthrough: Golden Set Evaluation.

Instead of defining "good spec" abstractly, anchor to concrete reality. Human provides known behaviors as ground truth. Agent checks if specs cover them. That's recall. Human spot-checks for hallucinations. That's precision.

**Precision + recall as the loss function.**

This is labeled data. Same principle as training a classifier. The human effort goes into curating golden sets, not writing specs.

Agreed on formula taxonomy:
- Baseline (all formulas share): core envelope, universal steps, universal validation, universal blocks
- Ecosystem specializations: frontend, backend API, mobile, game, CLI/library
- React/Vue/Angular share one formula. Node/Python/PHP backend share one formula.
