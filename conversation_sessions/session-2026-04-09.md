## Context

The project already existed with 8 content files that had significant duplication and inconsistency. This session was focused purely on reorganizing those files into a cleaner structure.

---

## What Happened

**User:** can we organize the files and contents? read all files and propose re-creating new files so its easier to follow and read

**Agent:** Read all 8 files:
- `VISION.md` (176 lines) -- High-level vision, architecture principles, spec types, sync overview, workflows
- `CORE_IDEA.md` (397 lines) -- Spec format philosophy, research findings, "spec shell" recommendation, spec kinds
- `TODO.md` (306 lines) -- Open questions, decisions to make, research areas, prototype priorities, done/in-progress/todo
- `BIDIRECTIONAL_SYNC.md` (329 lines) -- Deep dive on sync algorithm, conflict resolution, git integration, performance
- `blueprint-mode-compiled.md` (2278 lines) -- Massive compiled document combining everything from other files plus more
- `CLI_DESIGN.md` (412 lines) -- CLI commands, configuration, workflow examples
- `AGENT_ORCHESTRATION.md` (342 lines) -- Agent roles, context management, failure modes, multi-agent coordination
- `SPEC_FORMAT.md` (572 lines) -- YAML schema definitions for all spec types

**Problems found:**
1. Massive duplication -- `blueprint-mode-compiled.md` contained verbatim copies of VISION, SPEC_FORMAT, CLI_DESIGN, AGENT_ORCHESTRATION, and BIDIRECTIONAL_SYNC sections
2. `CORE_IDEA.md` duplicated `SPEC_FORMAT.md` -- both contained the same FunctionSpec/ComponentSpec YAML examples
3. `VISION.md` duplicated `CLI_DESIGN.md` -- same workflow examples appear in both
4. Mixed concerns in `TODO.md` -- open decisions, research areas, business questions, and task tracking all in one file
5. Naming inconsistency -- SCREAMING_CASE, lowercase-with-dashes, PascalCase all mixed

**Proposed structure:**
```
docs/
  00-overview.md              -- Vision, core thesis, differentiation (what VISION.md was)
  01-spec-format.md           -- Spec philosophy + concrete YAML schemas (merge CORE_IDEA + SPEC_FORMAT)
  02-cli-design.md            -- Commands, config, workflows (CLI_DESIGN.md, clean)
  03-agent-orchestration.md   -- Agent roles, context, failures (AGENT_ORCHESTRATION.md, clean)
  04-bidirectional-sync.md    -- Sync algorithm, conflicts, git hooks (BIDIRECTIONAL_SYNC.md, clean)
  05-decisions.md             -- Open questions only (extracted from TODO.md)
  06-roadmap.md               -- Done/In-Progress/Todo tasks + prototype priorities (extracted from TODO.md)
```

**Deleted:**
- `blueprint-mode-compiled.md` -- redundant, all content lives in individual docs
- `VISION.md` / `CORE_IDEA.md` / `SPEC_FORMAT.md` / `CLI_DESIGN.md` / `AGENT_ORCHESTRATION.md` / `BIDIRECTIONAL_SYNC.md` / `TODO.md` -- replaced by new structure

**User:** proceed

**Agent:** Created all 7 files under `docs/`, deleted the 8 old files. Verified:
```
Before: 8 files, 3,934 content lines, massive duplication, flat structure
After:  7 files, 2,194 lines, zero duplication, organized under docs/
```
